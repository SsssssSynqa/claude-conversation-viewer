# Claude 对话记忆查看器

一个用于查看和管理Claude对话历史的工具。

## 功能特点

- 📊 统计对话数据(字数、消息数、时间跨度)
- 🔍 搜索和过滤消息
- 💾 导出选中的对话或消息
- 🎨 自定义显示名称
- 💭 显示AI的思考过程

## 阅读详情与键盘操作

- 怀旧版（Claude 主题）把思考过程与工具调用收在一条轻盈的 inline 时间线里：默认只显示一行摘要（含耗时与数量），点击摘要或按 Enter/Space 展开后，可按需查看**完整**的思考原文、工具输入（`toolInput`）、与该工具**配对的输出**，以及独立的 `tool_result` 输出。长内容在受限高度内滚动/换行，不会只以截断作为唯一入口。
- 思考文本在屏幕上沿用既有的脱敏（敏感词替换为 `***`）处理，摘要预览与完整原文一致适用；此处仅限思考文本的屏幕显示脱敏，不代表对工具载荷做全量脱敏。
- 桌面阅读栏保持居中、最大 800px 宽，正文使用 16px 字号；对话标题下集中显示查看/选择、精选和导出操作。搜索、导出和统计页使用较宽的面板，手机上会调整留白并让控件换行。
- 选择消息后，批量操作栏会在阅读区底部占位；手机上位于底部导航上方，消息仍可独立滚动，操作按钮不会被导航遮住。
- 搜索摘要去除正文的 Markdown 排版标记，并保留代码中的标点和命中词高亮；搜索排版符号或链接地址时，会显示包含命中词的原始片段。
- 控件以原生 `button`/`checkbox`/`select` 实现并支持键盘：主题/语言/查看-选择模式等切换用 Tab 聚焦、Space（复选框）或 Enter/Space（按钮）操作；“导出此对话”菜单可用 Enter/Space 打开，方向键/Home/End 在选项间移动，Escape 关闭并把焦点还给触发按钮，点击菜单外部也会关闭，Tab 离开菜单时自动收起。
- 消息下方的复制、精选和选择操作在 hover 或消息内有键盘焦点时显示，触屏上保持可见。
- 焦点样式为轻盈、随主题融入的描边/填充，不会移除可见键盘焦点。

## 使用方法

1. 准备好你已经导出的 Claude 对话文件（见下方“如何导入导出的对话文件”）
2. 打开应用
3. 设置你和 AI 的显示名称
4. 上传 `conversations.json`，或本地已下载的对话 ZIP 分片，或这两者的组合
5. 查看、搜索、导出你的对话记忆

## 如何导入导出的对话文件

应用接受两类本地文件，可以混选、一次导入：

### 方式 A：单个 `conversations.json`（旧版/简单）

如果你已经有一个导出的 `conversations.json`，直接把它拖入上传区即可。

### 方式 B：清单（manifest）+ 本地分片导入（新版导出）

新版导出会先给一个 **manifest JSON**（清单）。它**只是一个下载列表，本身不包含任何对话内容**。应用识别到清单时会显示一份“下载指引”，而不是报错。

1. 按清单里的文件名，**手动**在 Claude 页面下载 `conversations` 分类的**全部分片**（例如 `conversations-000.zip`、`conversations-001.zip` …）。应用会在指引中列出文件名与分片数量。
2. 回到应用，把这些本地下载的 ZIP（可加 `conversations.json`）一起拖入上传区。
3. 应用在**浏览器本地**解压并解析，多个分片会在一次导入中合并、按 UUID 去重。

> 隐私：应用**不会**自动下载、请求或打开清单中的任何链接。清单中的说明文字会被忽略，不会被解析或执行。清单里的 URL/说明内容不会被保存或记录。对于清单中的链接，应用只会在你可点击的 HTTPS `claude.ai` 链接上（带 `noopener/noreferrer`）呈现，由你自行决定是否打开。

解析后的对话沿用浏览器的 IndexedDB 本地缓存，下次打开时可加载，也可在上传页点击“清除”。manifest 指引不会写入该缓存。

#### ZIP / 多文件约定（受支持的内部结构）

- 一个 ZIP 内，会被当作对话数据处理的成员需满足：文件名为 `conversations` 可选带数字后缀、以 `.json` 结尾（如 `conversations.json`、`conversations-000.json`、`data/conversations_1.json`），可位于嵌套目录中。
- `__MACOSX/` 目录以及 `.DS_Store`、`._*` 等系统噪声会被忽略。
- 每个匹配到的 JSON 成员内容需是：**对话对象数组**，或**单个含 `chat_messages` 数组的对话对象**（`chat_messages` 可为空数组）。
- 已观察到的其它导出分类（`light_metadata`、`projects`、`memories`、`feedback`、`frames`）会被忽略。
- 若选中的某个相关文件无法识别、损坏或格式不符，整次导入会**整体失败并给出当前语言下的错误**，不会静默产生部分成功。选择不支持的文件扩展名也会被拒绝。

#### 多文件与去重

- 可在一次操作中选择多个 `.json` / `.zip` 文件，全部作为**一个事务**导入：任一相关文件失败则整次不提交。
- 多个分片按 UUID 去重：**同一 UUID 以第一次出现的为准**，其余丢弃并计数；没有 UUID 的条目不会被去重。
- 全部文件只在**本机浏览器**中处理（读取、解压、解析均在工作线程完成），不会上传到任何服务器。

#### 关于清单 v1.0 与 ZIP 内部结构的验证说明（重要）

- 清单识别基于**观察到的字段结构**：`version: "1.0"`、`data_files[]`（含 `filename`、`category`、`part`、`batch_index`、`export_url`）。应用只把它当下载指引，不解析其内容。
- 已在本机用一个**真实手动下载的 manifest v1.0 清单**和一个**当前导出的 conversations ZIP** 对导入解析做过校验；该类 ZIP 的单个对话成员仍是既有的裸数组/`chat_messages` 结构。
- ZIP 中已知的对话文件名约定与内部结构，另有**合成测试数据**和旧版导出覆盖。**并非每个账号/导出变体都被验证过**；若某个真实 ZIP 使用了不同的内部文件名/结构，导入会明确报错，而不是猜测解析。
- 非对话分类（如 `memories`）的压缩包按包名类别被忽略——本工具只导入对话，不显示记忆等其它类别。
- 对话显示沿用既有 parser：只有空消息或附件、没有可显示消息内容的对话会被跳过；导出记录总数可能大于查看器里的对话数。

## 精选集（Collection）

在对话中点击“+精选”/“加入精选集”，或在选择模式下批量加入，即可把消息收进精选集，并在导出中心统一导出。

精选集保存在本机浏览器（localStorage）中：只要不清除浏览器数据，刷新页面或重新加载本地缓存后，精选仍然保留。数据只在本机处理，不会上传。

- 精选以来源对话 UUID 加来源消息 UUID 记录身份。重新导入同一份导出后，即使对话内消息被重新排序或插入，仍会指向原来那条消息，导出按当前来源顺序输出。
- 若导出里没有消息 UUID（例如解析器只能用 `msg_N` 位置编号），会改用发送者、时间戳和消息开头片段等证据匹配。匹配必须唯一：命中多条或无法确定时，该条保持“来源暂不可用”，不会凭位置猜测，也不会导出错误的消息。
- 对话或消息当前未加载时，条目会保留在精选集中并显示“来源暂不可用”，仍可预览和移除；之后加载其来源即自动恢复。不会静默删除。
- 旧版本只记录“对话:位置”的条目同样按上述证据保守匹配；匹配到来源消息 UUID 后会保存该身份，无法唯一确定时保持不可用。
- 缺少对话 UUID 的来源按名称、时间等来源标记及消息证据区分；来源标记改变或缺少可区分信息时，条目可能暂不可用。不会因为另一段对话含有相同消息，就把它当作原来源。
- 导出时无法定位的条目会被跳过，面板会显示可导出与暂不可用的数量；若全部不可用，则不会下载空文件。
- 精选也可以单独移除或整体清空。
